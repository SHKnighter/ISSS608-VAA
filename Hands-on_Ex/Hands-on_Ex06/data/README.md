# Exercise 6 data

The raw files were supplied by the user in `Hands-on Exercise 6.zip` on 3 October 2026.

Archive SHA-256: `04029df77cc48e2b866acce2a6106222a6b231370fefc09743f11b72752132fb`.

- `geospatial/myanmar_township_boundaries.*`: original Myanmar township shapefile and companion files, 330 features in WGS 84.
- `aspatial/Shan-ICT.csv`: 2014 household ICT indicators for 55 Shan townships.
- `rds/`: derived spatial data, clustering input and analysis results, regenerated by the QMD.

The QMD selects Shan (East), Shan (North) and Shan (South), then joins by township code. It derives household ownership rates per 1,000 households, uses five rates for clustering, and follows the supplied Chapter 12 teaching material.

Source chapter: https://r4gdsa.netlify.app/chap12.html
