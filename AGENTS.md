# Coursework workflow preferences

- Keep verification concise and economical. For routine Quarto coursework, run the affected page once and do one compact check of its output assets and navigation links.
- Reuse successful verification from the same task. Do not repeat renders, full-site audits, browser checks, or source reviews unless a subsequent change, failure, or specific unresolved concern requires it.
- When the user approves pushing an already verified exercise, inspect the Git change scope, push it, and perform one lightweight deployment check; do not rerun the analysis solely for publication.
- Keep coursework local for review until the user authorizes publishing.
