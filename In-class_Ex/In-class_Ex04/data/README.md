# Exercise data

These are the Hunan county boundaries and 2012 indicators supplied in the course data archive (`data.zip`), also used for Hands-on Exercise 4. The raw files are copied here without modification so this exercise can render using its own relative paths.

- `geospatial/Hunan.*`: county boundaries and shapefile companion files.
- `aspatial/Hunan_2012.csv`: 2012 county indicators.
- `aspatial/Dictionary.xlsx`: supplied variable dictionary.
